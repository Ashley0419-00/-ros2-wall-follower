# Attribution and project scope

This repository presents a team-based academic robotics implementation in a portfolio-ready structure. It should not be interpreted as sole authorship of every source file.

- The wall-follower starter implementation and vision examples retain their original Claude Sammut GPLv3 notices in source headers.
- The C++ interface header retains the ROBOTIS Apache-2.0 copyright and license notice.
- The repository adds and documents the integrated controller, wall/endpoint handling, return-to-start logic, landmark detection pipeline, simulation assets, validation evidence, and packaging around those foundations.
- Third-party TurtleBot3 model meshes are intentionally not vendored. Install the official TurtleBot3 simulation packages separately.

See `LICENSES/` and the individual source headers for the applicable license terms.
